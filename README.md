# TibiaCraft downloads

[Download the latest Windows release](https://github.com/Gabrielrgcg/TibiaCraft-Releases/releases/latest).

Choose **TibiaCraft-…-Setup-x64.exe** for the installed Windows client. Install it once to enable automatic updates. It checks on startup and hourly, downloads in the background, and saves your world before installing when you close the game. Use **Save & restart to update** to apply a downloaded update immediately.

The **windows-x64.zip** is a portable distribution with manual updates. Both distributions use the same persistent save folder at `%LOCALAPPDATA%\TibiaCraft\worlds`. Updates preserve worlds and desktop preferences.

This repository contains release downloads only. Source code is maintained in a separate private repository. New builds are released after validation and Windows desktop smoke tests pass.
